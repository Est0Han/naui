# Right panel example

Validate and enable this example through NaUi Plugins. It creates a right-side
panel with local echo text, an action button, and a multiline composer. It does
not call an AI service. Use **Show Example Right Panel** in the command palette
or **View → Toggle Right Panel** to reopen it after hiding it.

Drag the divider to resize it. Width, visibility and selected panel are saved
with UI settings and layout presets. Messages and unsent drafts are session-only.
Disabling/reloading the plugin removes its UI and guards late callbacks.
